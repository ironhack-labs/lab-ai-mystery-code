### Case 1: The Infinite Loop

**Prompt used:**
“What is wrong with this loop and how do I fix it?”

**AI helped me understand:**
- The loop was infinite because `i++` was missing
- The function checks if an array contains an even number

**What I learned:**
- Always update loop counters in while loops
- Small mistakes can break entire functions
- AI is helpful for debugging logic errors

**Fix applied:**
- Added `i++`
- Improved comments for clarity
