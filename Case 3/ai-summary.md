### Case 3: Over-Engineered Function

**Prompt used:**
“What does this function do and how can it be simplified?”

**AI helped me understand:**
- The loop increases `x` by 1, `b` times
- This is equivalent to simple addition: a + b
- The variable `y` is not used in the final result

**What I learned:**
- Some code is unnecessarily complex
- Loops can sometimes be replaced with simple math
- Always look for patterns that simplify logic

**Fix applied:**
- Replaced loop with direct addition
- Renamed function to `addNumbers`
- Removed unnecessary variables
